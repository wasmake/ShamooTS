# Winter 2.1.1 compatibility audit

## Audit baseline

This source audit is pinned to Winter **2.1.1**, commit [`421d39bf7efcdf14ebe9d2a085e858487d4945f8`](https://github.com/thewinterframework/winter/commit/421d39bf7efcdf14ebe9d2a085e858487d4945f8). Paths below are relative to that commit. The baseline includes its `core` and `paper` modules. Shamoo is source-concept compatible where stated, not Java binary, annotation, Guice, or behavior compatible.

Classifications mean: **Foundation** is represented by an honest Phase 1 contract; **Planned equivalent** preserves the concept with TypeScript APIs; **Intentional replacement** preserves the use case with different semantics; **Defect not preserved** explicitly rejects audited behavior; **Out of scope** belongs to another repository or phase.

## Confirmed source defects and risks

| Finding                              | Source evidence                                                                                                                                                                                       | Compatibility decision                                                                            |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Reversed module dependency/order     | `PluginModuleManager.java` builds the graph and `DfsGraph.java` reverses the DFS result, reversing the declared dependency/order interpretation.                                                      | Define direction normatively and add ordering tests; do not emulate.                              |
| Module processor not auto-registered | `module/processor/ModuleComponentAnnotationProcessor.java` lacks the `AutoService` registration used to discover processors.                                                                          | Generated metadata must use an explicit, testable compiler registry.                              |
| Single `ScheduledAt` undiscovered    | `ScheduledAt.java` is repeatable via `ScheduledAtContainer.java`, but discovery/handler registration addresses the container.                                                                         | Normalize one-or-many declarations in compiler metadata.                                          |
| Repeating unit mismatch              | `RepeatingTask.java` defaults to `MILLISECONDS`; `utils/TimeUnit.java` exposes `MILLIS`.                                                                                                              | Use one enum and reject unknown serialized values.                                                |
| Explicit `Primary` self-binding      | `PrimaryHandler.java` handles explicit type selection by binding the type to itself.                                                                                                                  | Bind requested token to selected provider and reject invalid targets.                             |
| `RequiresExpr` misses decorators     | `AbstractProcessorModule.java` applies component conditions separately from service decorator processing.                                                                                             | Conditions gate the complete declaration, including lifecycle and scheduling metadata.            |
| Disable conditions skipped           | `PluginModuleManager.java` does not evaluate component conditions for the disable stage.                                                                                                              | Specify condition snapshots and shutdown behavior before implementation.                          |
| `Expose` generation fragility        | `ExposeAnnotationProcessor.java`, `ExposeAnnotationProcessorAPI.java`, and `Expose*Template.java` rely on generated naming/casts and processing order.                                                | Replace with explicit facades and versioned manifests.                                            |
| No tests in repository               | The pinned tree has no `src/test` tree or test suite.                                                                                                                                                 | Require unit and integration characterization before claiming parity.                             |
| License provenance mismatch          | `build.gradle.kts` declares MIT publication metadata, but the pinned repository has no `LICENSE` file. `core/.../utils/TimeUnit.java` carries an Oracle GPLv2 with Classpath Exception source notice. | Do not copy source. Reimplement from behavior/contracts and retain a documented provenance audit. |

## Phase 1 conclusion

Phase 1 is not Winter parity. It supplies names, host boundaries, protocol versioning, and package topology needed to build and test later systems. Every matrix row requiring discovery, DI, lifecycle execution, expressions, scheduling, Paper registration, or code generation remains unimplemented until its stated phase and must not be presented as runnable.
