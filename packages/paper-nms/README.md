# @shamoo/paper-nms

Mojang and Paperweight mapped, type-only declarations pinned to the exact canonical NMS model. Runtime `JAVA_TYPES` descriptors are resolved by a host bridge; Java classes are not JavaScript exports. This package intentionally provides no stable compatibility promise. Compilation requires the `nms` permission and a Paper-only module. The exact model version and opaque totals are generated in `docs/platform-bindings.generated.md`.
