# @shamoo/velocity

Idiomatic Velocity entrypoints plus typed event, command, messaging, connection, and async-only scheduler contracts. `createVelocityHostApi` exposes ShamooRuntime's data-only event, command, task, proxy endpoint, service, and contract-event operations. `createVelocityCommunicationHandler` adapts neutral typed requests to the bounded Velocity channel. One-to-one generated Java declarations remain available from `@shamoo/velocity-raw`.
