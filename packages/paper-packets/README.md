# @shamoo/paper-packets

Type-only packet declarations and interception contracts pinned to the exact canonical Mojang and Paperweight model. Runtime `JAVA_TYPES` descriptors are resolved by a host bridge. Handlers receive live version-bound handles. Replacement packets must match the handler direction and protocol state. Compilation requires the `packets` permission and a Paper-only module. The exact model version and opaque totals are generated in `docs/platform-bindings.generated.md`.
